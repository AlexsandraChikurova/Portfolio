# Александра Чикурова — портфолио

Одностраничное портфолио: 13 проектов, фильтры по направлениям, галереи работ и контакты.

## Файлы сайта

- `index.html` — страница, тексты, фильтры и окна проектов.
- `portfolio.css` — стили галерей, карточек и движущейся ленты.
- `gallery.js` — переключение изображений стрелками, клавиатурой и свайпом.
- `assets/` — 28 изображений работ в формате WebP.
- `.nojekyll` — настройка публикации статического сайта на GitHub Pages.
- `.gitignore` — исключения для временных файлов.

Сайт не требует сборки или установки зависимостей. Шрифты загружаются из Google Fonts.

## Локальный просмотр

Откройте `index.html` в браузере или запустите в этой папке:

```sh
python -m http.server 8012
```

Затем откройте http://localhost:8012.

## Публикация на GitHub

1. Создайте публичный репозиторий.
2. Загрузите всё содержимое этой папки в корень репозитория. `index.html` должен лежать сразу в корне, рядом с `assets/`.
3. Откройте Settings → Pages.
4. Выберите Deploy from a branch, ветку `main` и папку `/(root)`, затем Save.
5. После публикации ссылка появится в разделе Pages.

Архивы исходников и резервные копии загружать в репозиторий не нужно.

## Изменение работ

Тексты и категории редактируются в `index.html`. Слайды перечислены в атрибуте `data-slides` каждой галереи: путь к изображению, подпись, ширина и высота. При добавлении работы сохраните изображение в `assets/` и укажите относительный путь.

Лента движется непрерывно. Работы открываются по нажатию на карточку; просмотр закрывается крестиком, клавишей Escape или нажатием на фон.
